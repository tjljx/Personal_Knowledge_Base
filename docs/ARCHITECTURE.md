# 架构与数据边界

本说明对应当前源码，不代表任何特定部署环境的运行状态。

```text
Vue 3 / Element Plus → FastAPI
                       ├─ PostgreSQL：账号、权限、文档版本、片段、任务、会话、图谱证据与预算
                       ├─ 原件存储：上传文件
                       ├─ Qdrant：可重建的当前片段向量投影
                       ├─ Ollama：本地嵌入
                       ├─ 本地重排服务：候选排序
                       └─ OpenAI 兼容模型网关：仅在知识库授权后用于问答、语义切片和图谱抽取
独立 worker → PostgreSQL 持久任务 → 解析、切片、索引与图谱处理
```

PostgreSQL 与原件是事实来源。删除、回滚和重解析后，检索必须按权限和当前有效版本核对结果；Qdrant 向量可以重建。关系证据保存在 PostgreSQL，图谱只用于寻找相关原文，不能单独作为答案事实。页码无法核实时保持为空。

代码中没有 RAGFlow、Neo4j、Redis 或 Celery 运行依赖。关键词召回基于数据库模糊匹配，向量与图谱召回可选；候选融合后可用本地重排。云模型通过可配置的 OpenAI 兼容接口调用，知识库默认关闭云端外发；启用后，相关资料片段可能发往配置的供应商，且会受应用内预算限制。预算是估算值，应以供应商账单为准。

API 和 worker 共用数据库及原件存储。生产环境建议 PostgreSQL；SQLite 仅用于本机试用或测试。健康接口 `/api/v1/health` 只检查应用与数据库，不能证明 Qdrant、Ollama、重排服务、worker 和问答链路健康。
