# 当前状态与限制

此页描述源码现有能力；部署者需自行验收其环境和资料。

| 范围 | 当前实现 |
| --- | --- |
| 账号、知识库与文档 | 管理员、成员权限、上传、版本、删除和回滚；服务端记录会话活动，默认 10 分钟空闲失效 |
| 解析 | Markdown、HTML、PDF、DOCX、PPTX、XLSX、部分图片；扫描件可调用本地 OCR；旧 `.doc` 可经 LibreOffice 转换；`.ppt`、`.xls` 仅保存原件 |
| 检索与问答 | 关键词召回、可选 Qdrant 向量和图谱线索、可选本地重排、流式问答与原文引用 |
| 图谱 | 自动抽取实体与关系、保存证据、浏览关系；无人工纠错锁定、实体合并或多跳路径查询 |
| 云调用 | OpenAI 兼容网关、知识库管理员逐库授权、应用内费用估算与预算 |

单文件默认上限为 50 MiB。PDF 解析还有限制页数；超大文档缺少分段、断点续跑和任务时长隔离。关键词检索尚非 BM25。自动生成的检索题和冒烟请求只适合回归，尚未完成公开可复现的人工评估集与正式质量验收。上线前应使用自己的资料核对权限、引用、解析和答案。
